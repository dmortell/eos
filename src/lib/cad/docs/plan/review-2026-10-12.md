## B. Bugs: data and output

- [x] **R15 Issued PDFs lose styling.** **Fixed 2026-10-12** (`phase8.md` › Review fixes). ✔
  - `freeze` (`domain/issue.ts:47`) keeps only `cls` / `clip`, plus `color` on lines.
  - It drops `dash` and `weight` on lines and circles, and `color` on text and circles.
  - So issued sheets print dashed lines solid, lose true lineweights and print layer-colored text in the class color.
  - `fingerprint` hashes the frozen list, so a style-only change never marks a sheet "Changed since".
  - *Fix:* keep those fields, and add a test.
  - **P1 · S**
- [x] **R16 Large writes fail part-way, and stale bulk batches overwrite edits.** **Fixed 2026-10-12.**
  - `persist/firestore.ts:34` awaits each 500-doc batch in turn.
  - **When a batch fails:**
    - the later batches are never sent;
    - their docs stay "pending" for the session: Saving… never clears, and remote changes to them are ignored;
    - after a reload they're gone.
  - **When the user edits during a bulk op of more than 500 docs:** the edit commits first, then the later bulk batch
    overwrites it, and the stale echo is applied locally too (`persist/sync.ts:87`).
  - *Fix:* commit all batches in order without awaiting each, then `allSettled`; on failure clear pending and re-read.
  - **P1 · M**
- [x] **R17 Explode ignores rotation, scale, owner and layer.** **Fixed 2026-10-12.** ✔
  - `explodeInsert` (`domain/blocks.ts:160`) only translates the shapes, and copies `levelId` only.

  - An insert on a sheet or view explodes into shapes with **no owner**: scope `sheet:undefined`, never drawn, never
    reloaded.
  - **P2 · S**
- [x] **R18 Deleting a level leaves sections, views and viewports pointing at it.** **Fixed 2026-10-12.**

- [x] **R20 DXF: unsafe layer names, and newlines inside text.** **Fixed 2026-10-12.**
